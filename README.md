# FtpKDV — Docker

Веб-файловый клиент с двумя рабочими панелями:
- **Левая панель** — локальная папка `./workspace`, смонтированная в контейнер.
- **Правая и левая панели** — каждая может работать с локальной папкой или собственным FTP-соединением.
- Передача файлов между локальной папкой и FTP; создание папок, переименование и удаление.
- Интерфейс на русском языке, работает в браузере.

## Запуск
1. Установите Docker Engine + Docker Compose или Docker Desktop.
2. Распакуйте архив.
3. В каталоге проекта выполните:
   ```bash
   docker compose up -d --build
   ```
4. Откройте `http://localhost:8080`.

Локальные файлы хранятся в `./workspace`.

## FTP-подключение
Введите адрес сервера, порт (обычно `21`), логин и пароль. Для анонимного входа можно указать `anonymous`.
Клиент использует FTP с пассивным режимом. Поддержка FTPS/SFTP в этой стартовой версии не реализована: SFTP — отдельный протокол.

## Важно по безопасности
- Не публикуйте порт в интернет без HTTPS и дополнительной аутентификации.
- FTP передаёт логин, пароль и данные без шифрования. Используйте только в доверенной сети; для удалённого доступа предпочтительнее SFTP/FTPS.
- Не используйте `SESSION_SECRET` по умолчанию в публичной среде.
- Удаление файлов необратимо. Локальная панель ограничена каталогом `workspace`.



## Сохранённые FTP-соединения

В верхней панели можно сохранить профиль через кнопку «Сохранить профиль», выбрать его из списка и удалить кнопкой «Удалить профиль». Для безопасности пароль не возвращается браузеру при выборе профиля: его нужно ввести вручную перед подключением. Профили сохраняются в `workspace/ftp_connections.json` и переживают перезапуск контейнера благодаря Docker volume `./workspace:/workspace`.

**Важно:** файл профилей содержит сохранённые пароли в открытом виде. Ограничьте доступ к каталогу `workspace` и не публикуйте его в GitHub или открытых резервных копиях. Используйте FtpKDV только в доверенной сети и защитите веб-интерфейс от постороннего доступа.


## Сохранение FTP-профилей при обновлении Docker

Профили хранятся в `workspace/ftp_connections.json` (внутри контейнера — `/workspace/ftp_connections.json`). Каталог `./workspace:/workspace` в `docker-compose.yml` обязателен: он сохраняет профили вне контейнера при пересоздании и обновлении образа. Не удаляйте папку `workspace` и не запускайте `docker compose down -v`, если хотите сохранить данные.

Для обновления на сервере, где настроен этот compose-файл:

```bash
docker compose pull
docker compose up -d --force-recreate
```

Если профили исчезли, сначала проверьте наличие `workspace/ftp_connections.json` на сервере и не перезаписывайте его пустым файлом.
